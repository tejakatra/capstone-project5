Created two Linux groups, developers and testers, and assigned users devuser and testuser to their respective groups. A restricted directory named /project_data was created and assigned to the developers group. Permissions were configured using chmod 770, allowing only the owner and members of the developers group to access the directory. Access verification confirmed that devuser could successfully create the file dev_test.txt, while testuser was denied access and could not create files within /project_data. This demonstrated the successful implementation of group-based access control and permission management in Linux.
